## Como usar a pasta

- dist: site para publicação; inclui os arquivos usados nas páginas.
- materiais-originais: cópias completas dos materiais enviados nesta conversa, incluindo versões em alta resolução. Não é necessário publicar essa pasta como parte do site.
- conferencia: inventários e resultados da conferência.
- .github: configuração de publicação de dist no GitHub Pages.

A publicação usa somente dist. Preservar nomes e pastas; a sequência de envio ao GitHub não controla a ordem das páginas ou fotos. Não enviar o ZIP como se fosse o site: primeiro extrair.

## Limites da confirmação

Todos os 253 materiais dos seis pacotes recebidos nesta conversa estão preservados. Isso não comprova que todos os materiais ou pedidos da conversa antiga foram recuperados. As 96 logomarcas dos parceiros foram preservadas do site, mas os originais desse conjunto não foram reenviados nesta conversa para comparação. Os sublogos e materiais auxiliares estão guardados; nem todos precisam aparecer nas páginas. Pendências visuais e nomes anteriormente apontados pelo usuário ainda exigem revisão. Não foi realizada revisão visual completa no navegador nem validação de links externos. Nenhuma alteração foi enviada ao site original ou ao GitHub.
